# College Placement Management System

## Project Overview
A console-based application developed using Python to manage college student placement records.

## Features
- Add student details
- View all student records
- Search students by roll number
- Update student information
- Delete student records
- Check placement eligibility based on CGPA
- Save records using JSON file handling
- Validate user inputs and prevent duplicate roll numbers

## Technologies Used
- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries
- Exception Handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python main.py`.

## Purpose
This project demonstrates Python programming fundamentals, data management, and file handling.
